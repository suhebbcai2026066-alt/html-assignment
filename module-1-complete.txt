TASK 1: What happens when you type a URL and press Enter?

Answer:
1. The browser parses the URL to find protocol, 
   domain and path.

2. DNS Lookup happens. Domain name is converted 
   to IP address.

3. Browser makes TCP connection with server 
   using 3-way handshake.

4. TLS handshake happens for secure HTTPS connection.

5. Browser sends HTTP GET request to server.

6. Server sends back response with Status 200 OK 
   and HTML, CSS, JS files.

7. Browser builds DOM and CSSOM, creates Render Tree 
   and displays the page.
